# To-Do List Console App

A lightweight, beginner-friendly Command Line Interface (CLI) application built in Python to manage daily tasks efficiently.

---

## Features

- **View Tasks:** Displays all current tasks in an organized, numbered list.
- **Add Tasks:** Allows users to add new items to the list with empty-input protection.
- **Delete Tasks:** Enables task removal by selecting its corresponding number, complete with input validation and error handling.
- **Interactive Menu:** Simple, loop-driven terminal interface.

---

## Tech Stack

- **Language:** Python 3.x
- **Libraries:** Built-in core Python (no third-party dependencies required)

---
