# Problem Statement & Project Overview

## Project Title
**CLI To-Do List Application**

---

## 1. Problem Statement
Managing daily tasks and personal assignments efficiently can be challenging without a structured tool. While many graphical task managers exist, they often come with unnecessary overhead and complex user interfaces. 

There is a need for a lightweight, fast, and terminal-based task management utility that allows users to quickly view, add, and remove tasks directly from a command-line environment without relying on third-party dependencies.

---

## 2. Objective
The primary objective of this project is to develop a modular, terminal-based To-Do List application using fundamental Python programming concepts.

### Key Objectives:
- Provide an intuitive, interactive menu for console-based navigation.
- Implement core task management operations:
  - **View:** Display current tasks with user-friendly numbering.
  - **Add:** Allow users to input new tasks with blank-entry prevention.
  - **Delete:** Remove tasks by selecting their corresponding list number.
- Ensure robust user input handling to prevent application crashes caused by invalid selections or type mismatches.

---

## 3. Academic & Development Declaration

### Integrity & Originality
- This project was developed as a hands-on programming exercise to demonstrate foundational Computer Science principles using Python.
- All core logic, control structures, and function implementations were written to reflect standard first-year software engineering practices.

### Scope & Constraints
- The application intentionally operates using standard Python built-in modules to maintain maximum portability across different operating systems without requiring external package installations (`pip`).
- The application currently uses in-memory data storage for dynamic task manipulation during execution.

---

## 4. Intended Audience
This application is designed for developer environments, command-line interface (CLI) enthusiasts, and introductory programming coursework demonstrations.
